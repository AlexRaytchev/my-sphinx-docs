Documentation for OptiOmega - Optiwave Python Modules
======================================================================

OptiOmega is a collection of python libraries used for electromagnetic **characterization and simulation** of **photonic integrated devices**.
It can be used along standard Optiwave's solver like **OptiSystem** and **OptiSPICE** for **circuit and system level simulation**
of photonic integrated circuits.
